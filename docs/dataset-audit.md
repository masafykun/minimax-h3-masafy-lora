# MASAFY dataset audit

確認日: 2026-08-08 (Asia/Tokyo)

## 結論

`提出バージョン` には画像が16枚あり、初回のキャラクターLoRAを試すには利用できます。
ただし、一般的な25～40枚構成より少なく、全画像にLINEスタンプ向けの文字や演出が
含まれるため、v1は「外見を覚えられるか」を確認するパイロットとして扱います。

## 検査結果

- 画像数: 16
- 解像度: 全て1000×1000
- 形式: JPEG 15枚、PNG 1枚
- アルファチャンネル: PNG 1枚のみ
- SHA-256完全重複: なし
- 主な共通要素: 茶色のレッサーパンダ、飛行帽風ゴーグル、ピンク色のスカーフ
- 主な偏り: 白背景、正面構図、文字入り、スタンプ的な強い表情

### 評価2枚

- `4_PCカタカタ.jpg`: 小物と作業ポーズ

### v1では除外2枚

- `12_闇マサフィー１.jpeg`
- `13_闇マサフィー２_下書きあり.jpeg`

闇マサフィーは色、雰囲気、演出が通常版と大きく異なります。通常外見LoRAへ混ぜると
キャラクター色や背景演出を不安定にする可能性があるため、別スタイルLoRA候補として
保留します。

## 制約と次の改善

- 文字が生成物へ混入する可能性があります。キャプションへ `Japanese sticker text` を
  明記し、文字とキャラクターを分離して学習しやすくします。
- 静止画だけなので、時間方向の一貫性や固有の動きは学習しません。
- v2では文字なし・無地背景・横向き・背面・座り・歩行などを追加し、25～40枚を目指します。
- 学習画像の自動増幅は評価リークを起こしやすいため、初回は実施しません。
